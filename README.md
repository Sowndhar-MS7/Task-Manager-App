# Task-Manager-App

TaskForge — React Task Management App
A feature-rich Task Management Application built with React, featuring routing, form validation, sortable tables, search, filtering, and pagination.

link - https://sowndhar-ms7.github.io/Task-Manager-App/

📸 Preview
> A dark-themed industrial UI with full CRUD task management, real-time search, and local storage persistence.
---
✨ Features
📋 Task Board — View all tasks in a sortable, filterable table
➕ Create Tasks — Add new tasks with full form validation
✏️ Edit Tasks — Update existing task details
🗑️ Delete Tasks — Remove tasks with confirmation modal
🔍 Search — Live search across task title and description
🔽 Filter — Filter by Status and Priority
↕️ Sort — Sort any column ascending or descending
📄 Pagination — 6 tasks per page with page controls
💾 Local Storage — Tasks persist after page refresh
📊 Stats Bar — Overview of Total, Completed, In Progress, Critical tasks
🔔 Toast Notifications — Feedback on create, update, delete actions
